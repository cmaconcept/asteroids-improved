# Screenshot Assets

Place repository screenshots in this folder.

Recommended files:

- `gameplay-main.png`
- `boss-meteor.png`
- `settings-panel.png`
- `gameplay-loop.gif` optional

Suggested capture rules:

- resolution: 1920x1080 or clean 16:9 crop
- no browser chrome if possible
- one screenshot during standard play
- one screenshot during boss meteor encounter
- one screenshot showing the settings panel
- optional animated GIF under 8 to 12 seconds
